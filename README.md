# Sonic Chess Academy

A marketing website for Sonic Chess Academy built with Next.js 16, Tailwind CSS v4, and Radix UI / shadcn components.

## Key Technologies

- **Next.js 16** (App Router) — server and client components
- **Tailwind CSS v4** — utility-first styling with `tw-animate-css`
- **Framer Motion** — page and component animations
- **Radix UI / shadcn** — accessible UI primitives
- **Lucide React** — icon library
- **TypeScript** — full type safety

## Pages

| Route | Description |
|---|---|
| `/` | Home page with hero, courses preview, why-choose-us, team, CTA |
| `/about` | About the academy |
| `/courses` | Available course levels |
| `/coaches` | Coach profiles |
| `/tournaments` | Tournament information |
| `/contact` | Contact form |

## Running Locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
